# K-Stock Console 권한 선언문

1. 콘솔은 상태를 표시하고 검증된 작업을 요청한다.
2. 콘솔은 정책·원장·주문·승인의 단일 진실 공급원이 아니다.
3. 콘솔은 `kstock` 내부 함수를 직접 호출하거나 정책 파일을 저장하지 않는다.
4. Console V1은 신규 주문을 만들거나 전송하지 않는다.
5. 거래 정지와 킬 스위치는 일반 작업 중에도 사용할 수 있다.
6. Human Interrupt는 프로세스 종료보다 공유 권위 상태 변경을 먼저 수행한다.
7. 전송 결과가 불명확하면 `UNKNOWN`으로 기록하고 대사한다.
8. LIVE 확인 문구는 빈 입력으로 시작하며 사용자가 직접 입력한다.
9. 사용자 확인은 주문 권한이 아니며 Final Guard와 SubmitPermit이 필요하다.
10. 구현되지 않았거나 승격 증거가 없는 기능은 실행 컨트롤로 노출하지 않는다.
