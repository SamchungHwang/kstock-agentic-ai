# K-Stock Console 권한 선언문

1. 사람 사용자는 `OWNER` 한 명뿐이다. 별도 사람 승인자·제출자 역할을 만들지 않는다.
2. PAPER는 `PAPER_PRIMARY`, LIVE는 `LIVE_PRIMARY` 고정계좌 하나만 사용한다.
3. 콘솔에는 계좌 선택·계좌 전환·실행 중 PAPER↔LIVE 전환 기능을 두지 않는다.
4. 콘솔은 상태를 표시하고 검증된 작업을 요청한다.
5. 콘솔은 정책·원장·주문·승인의 단일 진실 공급원이 아니다.
6. 콘솔은 `kstock` 내부 함수를 직접 호출하거나 정책 파일을 저장하지 않는다.
7. Console V1은 신규 주문을 만들거나 전송하지 않는다.
8. 거래 정지와 킬 스위치는 일반 작업 중에도 사용할 수 있다.
9. Human Interrupt는 프로세스 종료보다 공유 권위 상태 변경을 먼저 수행한다.
10. 전송 결과가 불명확하면 `UNKNOWN`으로 기록하고 대사한다.
11. LIVE 확인 문구는 빈 입력으로 시작하며 OWNER가 직접 입력한다.
12. OWNER 확인은 주문 권한 자체가 아니며 Final Guard와 SubmitPermit이 필요하다.
13. 내부 worker와 `SYSTEM_GUARDIAN`은 사람 사용자가 아니라 service actor다.
14. 구현되지 않았거나 승격 증거가 없는 기능은 실행 컨트롤로 노출하지 않는다.
