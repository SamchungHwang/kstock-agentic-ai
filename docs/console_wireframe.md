# K-Stock Console Wireframe

PAPER 세션 예:

```text
K-STOCK CONSOLE [PAPER] PAPER_PRIMARY · OWNER

전체 UNKNOWN | 게이트 CLOSED | 킬스위치 OFF | 감사 UNKNOWN
미해결 주문 0 | 세션 UNKNOWN | 마지막 대사 STALE | KIS UNKNOWN

[빠른 점검] [전체 점검] [계좌 조회] [공시 수집] [대사]
[게이트 상태] [감사 조회]

[거래 정지] [킬 스위치 발동]
```

LIVE 세션은 동일 화면에서 `LIVE · LIVE_PRIMARY`로 표시한다. 사용자가 계좌를 고르거나 실행 중 PAPER↔LIVE로 전환하는 컨트롤은 두지 않는다.

V1에서 구현되지 않은 V2·V3 기능은 비활성 버튼으로 미리 노출하지 않는다.
